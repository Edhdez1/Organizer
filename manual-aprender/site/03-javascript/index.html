Módulo 03 — JavaScript

Objetivo del módulo: aprender JavaScript, el lenguaje que da lógica e interactividad a una página: responder a clics, validar formularios, mostrar y ocultar cosas, pedir datos a un servidor. Aquí es donde, por fin, programas de verdad (datos, decisiones, repeticiones del Módulo 00 hechas código).

Si HTML era la estructura de la casa y CSS la pintura, JavaScript es la electricidad y los aparatos: los interruptores, el timbre, las cosas que reaccionan.

¿De dónde sale esto en TUS proyectos?

  • tunal-digital/sitio-web/main.js es JavaScript "puro" (vanilla): controla el menú, el cambio de idioma, el chat con IA, el formulario y el cotizador de tu sitio. Es nuestro ejemplo real.
  • JavaScript es, además, la base de TypeScript y React (módulos 05 y 06). Dominarlo aquí hace que todo lo demás sea mucho más fácil. Es el lenguaje más importante del manual.

¿Qué vas a poder hacer al terminar?

  • Guardar datos en variables y conocer los tipos (texto, número, booleano, listas…).
  • Tomar decisiones (if/else) y repetir tareas (bucles).
  • Crear funciones (bloques de código reutilizables) que reciben y devuelven datos.
  • Manipular la página en vivo con el DOM (cambiar textos, mostrar/ocultar, reaccionar a clics).
  • Pedir datos a internet con fetch y entender async/await (como hace tu chat con IA).
