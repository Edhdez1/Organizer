Capítulo 01 — ¿Qué es HTML?

Tu primera línea de código de verdad está a unos minutos. Pero antes, entendamos qué es HTML y, sobre todo, qué no es, porque eso evita confusiones que arrastra mucha gente.

1. HTML describe la estructura, no da órdenes

🟦 ¿Qué significa? — HTML

HTML significa HyperText Markup Language ("lenguaje de marcado de hipertexto"). Es el lenguaje con el que se describe la estructura y el contenido de una página web: esto es un título, esto un párrafo, esto una imagen, esto un enlace. ¿Para qué sirve? Para decirle al navegador qué hay en la página y qué papel cumple cada parte. Es el esqueleto de toda web.

Fíjate en las dos palabras clave:

🟦 ¿Qué significa? — Marcado (markup)

"Marcado" quiere decir que etiquetas el contenido para indicar qué es cada cosa, igual que un editor marca un manuscrito ("esto va en negrita", "esto es un título"). No le das órdenes paso a paso (eso es programar, como en JavaScript): solo describes la estructura. Por eso, técnicamente, HTML es un lenguaje de marcado, no un "lenguaje de programación".

🟦 ¿Qué significa? — Hipertexto

"Hipertexto" es texto que contiene enlaces a otros textos o páginas. Es la idea que hace que la web sea una "telaraña" (web): puedes saltar de una página a otra haciendo clic. Esos saltos son los enlaces (los verás en el capítulo 02).

💡 Tip — La analogía de la casa (te servirá todo el módulo)

  • HTML = la estructura de la casa: paredes, habitaciones, puertas. Qué hay y dónde.
  • CSS (módulo 02) = la decoración: pintura, colores, muebles. Cómo se ve.
  • JavaScript (módulo 03) = la electricidad y los aparatos: interruptores, timbre. Qué hace cuando interactúas. Una casa puede existir solo con estructura (HTML solo): se ve sosa, pero funciona.

2. La pieza básica: la etiqueta

HTML se escribe con etiquetas. Veamos su anatomía con calma.

🟦 ¿Qué significa? — Etiqueta (tag) y elemento

Una etiqueta es una palabra entre signos < y > que marca el inicio o el fin de algo. Casi siempre van en pareja: una de apertura y una de cierre (con /). Lo que envuelven, junto con las etiquetas, forma un elemento.

html <p>Hola, mundo</p> Aquí: - <p> es la etiqueta de apertura (p = paragraph, párrafo). - Hola, mundo es el contenido. - </p> es la etiqueta de cierre (la barra / indica "aquí termina"). - Todo junto —<p>Hola, mundo</p>— es un elemento párrafo.

Visto como dibujo:

   apertura        cierre
     │                │
    <p>  Hola, mundo  </p>
          │
       contenido

🟦 ¿Qué significa? — Atributo

Un atributo es información extra que se le da a una etiqueta, escrita dentro de la etiqueta de apertura, con la forma nombre="valor". Por ejemplo, un enlace necesita saber a dónde lleva: html <a href="https://tunaldigital.com">Visita Tunal Digital</a> Aquí href es el atributo (de hypertext reference, "referencia de hipertexto") y "https://tunaldigital.com" es su valor (el destino). <a> es la etiqueta de "ancla" (anchor), que crea enlaces.

⚠️ Cuidado — Casi todas las etiquetas se cierran (pero no todas)

La mayoría van en pareja (<p>…</p>). Unas pocas no envuelven nada y por eso no se cierran, como la imagen <img> o el salto de línea <br>. Se llaman elementos "vacíos". No te preocupes por memorizarlas: el editor te avisa.

3. Tu primera página web (paso a paso)

Vamos a crear una página real. Cuando tengas tu computadora, sigue esto; por ahora, léelo y entiéndelo.

Paso 1. Abre VS Code y crea un archivo nuevo llamado index.html.

🟦 ¿Qué significa? — index.html y por qué ese nombre

Por convención, la página principal de un sitio se llama index.html. Cuando entras a tunaldigital.com sin especificar una página, el servidor te entrega su index.html. "Index" = índice, la portada/entrada. Tu sitio real tiene su index.html en tunal-digital/sitio-web/index.html.

Paso 2. Escribe esto exactamente:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>¡Hola! Esta es mi primera página</h1>
    <p>La estoy escribiendo mientras aprendo HTML.</p>
  </body>
</html>

Paso 3. Guarda el archivo (Ctrl+S / Cmd+S) y ábrelo con doble clic: se abrirá en tu navegador y verás tu título y tu párrafo. ¡Acabas de crear una página web!

Ahora desarmemos lo que escribiste, línea por línea:

🔎 Línea por línea

  • <!DOCTYPE html> → le dice al navegador "esto es una página HTML moderna". Siempre va primero. No es exactamente una etiqueta, es una declaración.
  • <html lang="es"> → la etiqueta que envuelve toda la página. El atributo lang="es" indica que el idioma es español (ayuda a buscadores y lectores de pantalla).
  • <head> → la cabecera: información sobre la página que no se ve en el cuerpo (título, idioma, enlaces a estilos). Lo verás a fondo en el capítulo 03.
  • <meta charset="UTF-8"> → fija la codificación de caracteres a UTF-8, que permite acentos y la ñ. Sin esto, "programación" podría verse como "programaci??n".
  • <title> → el texto que aparece en la pestaña del navegador.
  • <body> → el cuerpo: aquí va todo lo que se ve en la página.
  • <h1> → un título de nivel 1 (heading 1), el más grande e importante.
  • <p> → un párrafo.

🟦 ¿Qué significa? — Anidar (anidamiento)

Fíjate que unas etiquetas van dentro de otras: <h1> está dentro de <body>, que está dentro de <html>. A esto se le llama anidar, como muñecas rusas. La regla de oro: lo que se abre dentro de algo, debe cerrarse dentro de eso mismo (no se cruzan). La sangría (los espacios al inicio de cada línea) es solo para que tú lo leas mejor; al navegador le da igual, pero a ti te salva de errores.

4. Cómo "ve" el navegador tu HTML: el DOM

Cuando el navegador lee tu HTML, no se queda con el texto: construye un árbol en su memoria.

🟦 ¿Qué significa? — DOM (modelo de objetos del documento)

El DOM (Document Object Model) es la representación en forma de árbol que el navegador crea a partir de tu HTML: cada etiqueta se vuelve un "nodo" (una rama) con sus hijos dentro. Tu página de ejemplo se vuelve este árbol: html ├── head │ ├── meta │ └── title └── body ├── h1 └── p ¿Por qué importa? Porque en el módulo 03, JavaScript modifica ese árbol para cambiar la página en vivo (mostrar/ocultar, cambiar textos). Por eso "DOM" es una de las palabras que más oirás. De momento, basta con que sepas: tu HTML se convierte en un árbol llamado DOM.

5. Las herramientas de desarrollador (tu rayos X)

Todo navegador trae una herramienta para ver el HTML por dentro de cualquier página.

💡 Tip — Inspecciona páginas reales

En tu computadora, sobre cualquier web, pulsa F12 (o clic derecho → "Inspeccionar"). Se abre el panel de Herramientas de desarrollador; en la pestaña Elements (Elementos) verás el HTML —el DOM— de esa página. Es la mejor forma de aprender: mira cómo están hechas las páginas que te gustan. Cuando llegues al módulo 02, podrás incluso cambiar colores ahí mismo (temporalmente) para experimentar.
